# Local Memory Template

Copy this file to `docs/agent-memory/local/<your-name>.local.md` for private,
machine-specific notes.

## Good Fits

- personal test accounts
- local ports and tunnels
- temporary mock endpoints
- one-off debugging breadcrumbs
- experimental workflows that are not ready to share

## Keep Out Of Git

- secrets
- tokens
- passwords
- anything that only applies to one machine
